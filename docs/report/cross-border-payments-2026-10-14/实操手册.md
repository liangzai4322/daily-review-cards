图片提供了一组可用工具和一条美国公司方案，但省略了开户资格、合法入金、商户审核、资金回国和持续报税。它适合作为线索，不能直接当作人人适用的教程。

**本次已完成：**阅读原图；联网读取银行服务商、支付平台、税务与监管机构的官方资料；对 12 个核心公开页面进行本机 HTTP 读取检查，核对关键字段；追查官方资料之间的费用冲突。

**本次没有完成的实测：**使用你的身份开户、Stripe 沙盒交易、真实付款、真实提现、下一期订阅续费。下文的“验收步骤”是实施时要执行的操作，不能当作本次已经通过的结果。

适用口径：以中国大陆个人或企业的常见需求为主，另列真实居住在其他地区的分支。你的实际常住地、税务居民身份、现有公司和业务类型尚未知；不根据设备时区推定这些事实。

### 最重要的六个结论

1. **仅购买海外软件，通常先核对商户地区资格，再检查现有银行卡和 PayPal。**不应仅为支付月费默认注册美国公司。Claude 当前网页付款不接受 PayPal，这条替代路径对它不适用。[Claude 付款说明](https://support.claude.com/en/articles/9402418-why-was-my-card-declined)
2. **Wise 多币种余额、美元收款详情和 Wise 卡是三项不同权限。**当前余额支持名单包括 China；个人发卡名单不包括中国大陆；Wise Business 美元收款详情还单列了中国地址限制。[余额](https://wise.com/help/articles/2813542/where-do-i-need-to-live-to-hold-money-with-wise)、[卡](https://wise.com/help/articles/2968915/can-i-get-the-wise-card-in-my-country)、[美元详情](https://wise.com/help/articles/2810318/can-i-get-usd-account-details)
3. **Atlas → 美国公司 → Mercury → Stripe 是有条件的业务路径。**公司成立、银行账户获批、Stripe Payments 获批是三个结果，不能相互替代。Atlas 官方明确不保证 Stripe Payments 审核通过。[Atlas 注册说明](https://docs.stripe.com/atlas/signup)
4. **“自己用支付宝买自己的商品，就有钱支付”不能作为可靠入金方法。**没有真实交易与交付的循环自买不能替代贸易背景。万里汇结汇需要真实订单；真实关联交易也应按具体平台要求申报和审核。[万里汇结汇说明](https://www.worldfirst.com.cn/content/articles/b2c_portal/cgyqpoke)、[外汇局真实性审核说明](https://www.safe.gov.cn/safe/2019/0701/13551.html)
5. **海外账户收到钱，不代表可以直接提现到中国个人银行卡。**先确定款项属于货物销售、服务收入、工资、利润分配还是其他性质，再确定收款主体和申报资料。Airwallex 公布的人民币本地付款场景主要围绕中国出口货物，不能直接套用到所有 SaaS 或咨询业务。[Airwallex 中国付款说明](https://help.airwallex.com/hc/zh-cn/articles/4633986370447-如何向中国境内付款)
6. **公司、美国号码、美国服务器、住宅 IP 不构成 Claude 使用资格或“不封号”保证。**官方另有支持地区、付款地区和企业控制关系规则。[Claude 支持地区](https://support.claude.com/en/articles/8461763-where-can-i-access-claude)、[Anthropic 企业限制公告](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)

## 2. 全流程：先区分四条链路

### A. 只支付海外软件费

```text
真实使用地区与商户资格
    → 商户支持的付款方式
    → 现有国际银行卡 / PayPal / 合资格的 Wise 卡
    → 一次购买成功
    → 下一期续费与账单核对
```

只要 A 能满足需求，就不必自动走美国公司方案。

### B. 以现有中国主体开展跨境业务

```text
真实货物或服务业务 + 主体资料
    → 平台确认支持该行业、主体与付款来源
    → 企业认证、收款账户或收单功能获批
    → 海外客户支付 + 实际交付
    → 提交订单 / 合同 / 发票等真实资料
    → 海外业务支出，或符合条件的结汇回国
```

万里汇、Airwallex、XTransfer 的具体适用范围不能互相推定。特别是数字产品、咨询和 SaaS，应先确认回国通道是否接受该款项性质。

### C. 确有美国公司经营需要

```text
主体与业务适配、年度成本评估
    → 选择 LLC 或 C corporation、注册州和服务商
    → 公司成立 + EIN
    → Mercury 等企业资金账户审核
    → Stripe Payments 独立审核
    → Payment Links / Checkout / 订阅上线
    → 客户真实付款
    → Stripe 可用余额 → 企业银行账户
    → 业务消费 / 真实供应商付款 / 经核准的资金回国路径
    → 持续记账、州税、联邦申报和必要的所在地申报
```

这里采用便于管理的常规顺序。它不是唯一技术顺序：Atlas 对符合条件的公司提供 EIN 未下发前的部分 Payments 与银行功能，其他第三方可能仍要求先取得 EIN。**不能把成立公司后的有限预开放功能当作所有功能都已获批。**[Atlas 前置功能说明](https://docs.stripe.com/atlas/signup)、[银行选择](https://docs.stripe.com/atlas/payments-business-bank)

### D. 将海外资金汇回中国

```text
确定款项归属与性质
    → 确定国内合法收款主体
    → 收款银行 / 持牌通道确认支持与资料要求
    → 完整真实单证及申报
    → 合法实际款项的小额首笔到账
    → 对账、留存、税务处理
```

**C 的银行账户开好，并不代表 D 自动打通。**

### 选哪条路线

| 你的真实需求 | 建议起点 | 进入美国公司方案的条件 |
|---|---|---|
| 每月买几个海外工具 | A | 现有付款路径不能满足，且有明确经营用途和可承担的维护成本 |
| 已有中国企业/个体户，出售出口货物 | B | 客户、平台或经营安排确需美国主体时再评估 |
| SaaS、数字产品、咨询收款 | 先明确合同主体、收单资格和服务收入回国渠道，再选 B/C | 有持续业务、真实产品、可审核资料和可用结算安排 |
| 面向美国投资人融资 | C，重点评估 Delaware C corporation | 股权、融资文件和税务结构确实符合计划 |
| 真实居住在日本等支持地区，只需个人支付 | 按真实所在地评估当地银行卡和 Wise 卡 | 不因已有海外地址就默认成立美国公司 |

上述是实施建议，不是任何平台给出的开户保证。

## 3. 开始前：建立一份资料清单

### 3.1 资料包

| 类别 | 准备内容 | 自检方法 |
|---|---|---|
| 本人身份 | 有效护照/身份证，姓名、生日、国籍 | 与证件完全一致；不使用他人身份 |
| 实际居住 | 真实常住地、可验证住址、平台接受的近期证明 | 手机号、IP 或邮箱不能替代住址证明 |
| 公司 | 法定名称、注册州/地区、成立文件、组织章程或 Operating Agreement | 区分品牌名与法定公司名 |
| 税号 | EIN 官方确认文件；现有所在地税务资料 | 不把服务商邮件里的数字当作完整税号证明 |
| 所有人与控制人 | 股权链、受益人、管理负责人 | 按各平台自己的披露阈值填写，不混用阈值 |
| 产品与网站 | 功能、价格、付款周期、交付办法、客服、退款/取消规则 | 陌生人能理解你卖什么、如何获得商品/服务 |
| 商业证明 | 客户合同、订单、发票、交付记录、物流或服务履约证明 | 主体、金额、币种、交易性质相互对应 |
| 资金 | 初始资金来源、预计月收款量、客户国家和付款方式 | 能说明钱从哪里来、为什么进入这个账户 |
| 账户安全 | 独立密码、通行密钥/验证器、恢复码、本人可控制的邮箱与号码 | 关键账户能够独立恢复 |

### 3.2 四种地址不能混用

| 地址 | 作用 | 操作原则 |
|---|---|---|
| Registered agent address | 接收注册州要求的法律通知 | 不默认用作公司一般邮件或实际办公地址 |
| Company legal address | 注册与账户法律记录 | 按目标平台要求填写；Mercury 要求其法律地址是美国实体街道地址 |
| Principal/physical business address | 实际经营和日常工作地点 | Mercury 可接受可验证的境外或住宅地址；不接受虚拟地址、邮箱中心、注册代理地址替代 |
| Owner residential address | 受益人真实居住地 | 用本人真实住址；不以 VPM 取代 |

Mercury 的法律地址、实际经营地址和邮寄地址有独立定义；Atlas 接受某类地址不代表 Mercury 或 Stripe 同样接受。[Mercury 地址规则](https://support.mercury.com/hc/en-us/articles/28769699533588-Company-address-requirements)、[Atlas 注册代理说明](https://docs.stripe.com/atlas/signup)

### 3.3 必要术语

| 术语 | 本文中的意思 |
|---|---|
| EIN | 美国企业联邦税号，不是个人身份号码 |
| UBO / beneficial owner | 最终受益所有人；具体披露门槛按平台规则 |
| KYC | 身份与业务核验 |
| 3DS | 发卡行参与的网上付款身份验证，可能需要短信或银行 App 确认 |
| ACH / wire | 不同的银行转账渠道，银行详情可能不同 |
| Payments / acquiring | 收单：让客户能用银行卡等支付给商户 |
| Payout | 把支付平台可用余额结算到银行账户 |
| Settlement / 结汇 | 前者通常指交易资金结算；结汇特指外币换成人民币，不是同一个动作 |

## 4. 路线 A：个人购买海外工具

### 操作步骤

1. 打开**目标商户自己的**支持地区、付款方式和订阅规则。先判断使用资格，再判断银行卡。
2. 检查现有卡是否支持商户要求的 Visa/Mastercard 等卡组织、境外线上消费、对应币种及 3DS。实际限制向发卡行核对。
3. 账单地址按发卡行记录填写。不要为了通过页面填写虚构美国地址。
4. 如果商户明确接受 PayPal：在适用的本地 PayPal 账户中完成认证并关联本人银行卡，比较结算币种和兑换成本后付款。
5. 如果考虑 Wise：分别核对余额、收款详情、卡资格。大陆真实居民不能仅凭“支持 China 持有余额”就申请个人 Wise 卡；在支持发卡地区真实居住的人按当地规则申请。
6. 购买一项确实需要的服务，保存订单、商户账单与发卡行流水。这里是正常购买外部商户服务，不是给自己的店铺刷单。
7. 有订阅需求时，检查余额/额度和续费通知；到下一期实际扣款并核对后，才把“自动续费”记为通过。
8. 不需要续费时，在商户订阅管理中取消并保留确认；另检查 PayPal 自动付款授权是否需要管理。

PayPal 全球服务条款允许关联信用卡、借记卡或银行账户；关联卡可以作为购物资金来源，**信用卡不能直接为 PayPal 余额充值**。它也不能让不接受 PayPal 的商户接受 PayPal。[PayPal 全球服务条款](https://www.paypal.cn/portal/paypal-worldwide-services-terms-and-conditions)

### 验收标准

- [ ] 目标商户允许我的真实使用情况。
- [ ] 一次正常购买成功，商户账单和银行卡扣款一致。
- [ ] 需要自动续费的服务已完成下一周期实际扣款。
- [ ] 知道退款、取消和银行卡故障时的处理入口。

**停止条件：**商户不支持实际使用地区，或本人付款方法不符合规则。此时“换美国 IP”不是资格验收。

## 5. 路线 B：现有中国主体的跨境收付

### 5.1 开户前先做业务适配

| 平台 | 官方资料能确认的能力 | 本次不能替你确认的事项 |
|---|---|---|
| 万里汇 WorldFirst | 跨境商户账户、真实订单结汇、World Card 业务支付 | 你的业务、入金来源、网关、收款主体是否被接受 |
| Airwallex 空中云汇 | 全球企业账户、收款/换汇/付款、企业卡和收单产品 | 你的注册主体具体开通哪些功能；数字服务收入能否按所选通道回国 |
| XTransfer，若原图 xt 指它 | B2B 贸易收款方向 | xt 的真实名称；当前是否支持你的服务类业务和具体主体 |

Airwallex 官网列出中国企业服务，但产品可用性依公司注册地和审核而变。[Airwallex 中国企业账户](https://www.airwallex.com/cn/business-account)、[开户地区说明](https://help.airwallex.com/hc/zh-cn/articles/4408591334937-支持开户的国家和地区)

XTransfer 的一篇 2022 年官方教程限定 B2B 实物出口、不支持个人认证及服务贸易。**旧教程不能证明 2026 年的全部现行边界**；本次没有取得明确覆盖你的 SaaS/咨询业务的最新准入证明，故该分支保持待核实。[XTransfer 官方原教程](https://www.xtransfer.cn/tagInfo/news/63033d69814e6600013a9700)

### 5.2 正式操作

1. 写下实际销售内容、注册主体、客户国家、付款方式和预计月流水。
2. 在平台官网对照准入条件；有关键缺口时，用第 10 节模板询问官方支持，取得对应产品与主体的具体答复。
3. 完成企业/商户认证，提交真实业务和所有人资料。
4. 按客户付款方式选功能：银行转账需要收款账户；银行卡/钱包付款需要收单或支付网关。**获得一个收款账号，不代表已有银行卡收单功能。**
5. 如果通过店铺或网关收款，完成对应授权和主体核对。
6. 接受真实客户付款并完成交付；保存合同/订单、付款和履约记录。
7. 需要海外业务消费时，再申请被批准的企业卡，设置额度和通知。
8. 需要结汇回国时，核对资金性质、订单资料、收款人范围及额度；通过后的合法实际款项再进行首笔转款与对账。

World Card 当前 FAQ 说明：默认没有信用额度，交易从万里汇账户余额扣除，支持账户余额共享。**旧“先向旧版万里付卡充值”的教程不应直接套用到 World Card。**有卡仍不等于有合法余额来源，也不等于每个海外商户都接受这张卡。[World Card FAQ](https://www.worldfirst.com.cn/content/articles/vcc_qusetions/ssgyqn6e)

### 5.3 不采用的入金办法

不通过虚构商品、无真实交付的自买自卖或循环付款来创造可提取的跨境余额。即使支付技术上成功，也没有证明资金来源和交易背景获平台认可。使用被平台允许的真实客户销售收入，或被该账户明确接受的合法资金来源。

万里汇要求店铺授权或真实订单流水以建立结汇额度；在符合其真实贸易规则的情况下，相关结汇不占个人年度 5 万美元便利化结汇额度。这个结论只适用于其合资格的真实贸易结汇，不能泛化为任何款项都可绕过个人额度。[万里汇结汇额度说明](https://www.worldfirst.com.cn/content/articles/b2c_portal/cgyqpoke)

## 6. 路线 C：美国公司 → Mercury → Stripe

### 第 1 步：先决定是否值得成立公司

先得到三项答案：为什么需要美国主体；客户和产品是否真实可审核；资金最终要留在海外支付业务成本，还是要汇回国内。

如果只有少量软件月费，先完成路线 A。若没有能解释的业务、初始资金来源与年度申报安排，暂不提交注册。

### 第 2 步：选择注册州、主体和服务商

| 选择 | 更常见的用途 | 注意事项 |
|---|---|---|
| Delaware C corporation | 股权融资、引入投资人 | 公司税、股权文件、州特许税、年报和可能的跨境分红处理 |
| Delaware LLC | 较灵活的成员经营结构 | 外国所有人税务处理不等于“免税”；可能涉及 5472 等申报 |
| Wyoming LLC | 不依赖特拉华融资结构、想比较州维护成本 | 需另外注册，不能在 Atlas 里选择怀俄明；仍有联邦及实际经营地义务 |
| 注册服务商 | 代办成立、注册代理、可能代办 EIN | 分别核对政府费、服务费、续费、税务服务范围；不接受保证开户或保证收单的口头承诺 |

Atlas 官方仅支持特拉华 LLC、C corporation 及 C corporation 子公司。[Atlas 主体类型](https://docs.stripe.com/atlas/company-types)

这张表是用途比较，不能单独决定你的税务结构。已有资产/IP、多人股权、融资或跨境税务情况会实质影响选择；应先取得针对这些具体问题的专业意见和报价。

### 第 3 步：准备能被理解的真实业务

完成产品/服务介绍、价格、交付规则、客服联系方式、退款/取消说明和隐私条款。经营范围与提交给银行、Stripe 的说明相符；保存实际客户或计划经营的证据。

推荐先做最小但完整的网站：访客能找到商品、主体、价格、售后与联系方式。不得用与实际业务无关的网站通过审核后再经营另一类业务。

### 第 4 步：注册并保存法律文件

如果选 Atlas：从官方入口填写公司类型、法定名称、公司说明、公司地址和电话、创始人、持股及角色；核对模板中的资产/IP 与股权安排后签署。成立后保存州盖章文件、章程/Operating Agreement、所有权文件、注册代理信息和成立日期。

如果股权安排涉及归属期及 83(b) 税务选举，核对并保存实际提交证明；仅有选举模板不等于已经提交。Atlas 的自动处理仍需与实际股权安排对应。[Atlas 股权与注册流程](https://docs.stripe.com/atlas/signup)

Atlas 当前一次性费用为 **$500**，含政府费用和首年注册代理；以后注册代理 **$100/年**。州年税、记账与所得税申报不包含在“代理续费”里。[Atlas 官方价格](https://stripe.com/atlas)

### 第 5 步：取得 EIN，并核对官方证明

EIN 是美国企业联邦税号。IRS 直接申请不收取申请费；服务商可能另收代办服务费。公司名称应与注册文件对应，主体应先成立再申请税号。[IRS EIN 指南](https://www.irs.gov/businesses/employer-identification-number)

Atlas 无 SSN 创始人的 EIN 取得时间，官方通常给出成立后 **10–30 个工作日**；不是“两天注册完成”就等于税号也已取得。不要伪造 SSN/ITIN，按官方支持的非美国创始人流程办理。[Atlas EIN 流程](https://docs.stripe.com/atlas/signup)

**验收：**获得官方 EIN 确认文件，并核对法定名称、税号和地址。服务商发来的进度通知不等于税号已下发。

### 第 6 步：申请 Mercury 企业账户

按真实资料提交公司文件、税号或平台接受的相应材料、经营内容、初始资金来源、现有/计划美国业务、实际经营地址，以及受益所有人和控制人资料。Mercury 可接受非美国居民创始人的申请，但要求美国注册公司及现有或计划中的美国经营活动；最终以完整申请审核为准。[Mercury 开户资格](https://support.mercury.com/hc/en-us/articles/28770467511060-Eligibility-and-requirements-for-opening-a-Mercury-account)

申请前分别检查：

- 居住地/业务涉及地是否在禁止名单；判断依据包括居住和业务所在地，而不只是国籍。[禁止地区](https://support.mercury.com/hc/en-us/articles/28771710754580-Prohibited-countries)
- 公司法律地址与实际办公地址是否符合其不同规则。[地址要求](https://support.mercury.com/hc/en-us/articles/28769699533588-Company-address-requirements)
- 发卡和邮寄是否受限。当前中国列在**实体卡邮寄限制**中，不在该页的实体卡及虚拟卡共同禁发名单中；不能把邮寄限制误读为虚拟卡一概不可申请。[发卡规则](https://support.mercury.com/hc/en-us/articles/34087163095572-Restricted-countries-for-card-issuance)

**验收：**账户获批、所需资金功能可用、实际银行详情可下载。Mercury 是金融科技公司，银行服务由合作银行提供；不能将品牌名直接等同为银行法人。

### 第 7 步：合法入金和申请业务卡

仅接受可解释、可记录且被账户允许的资金：真实客户款项、合法公司资本/借款或其他获准资金来源。初始从中国出资是否可行，要按资金性质和银行要求先核对，不把“个人每年 5 万美元便利化额度”当作海外公司投资通行证。

账户有可用资金后，在正式卡管理中申请适用的虚拟业务卡，设置用途、限额与提醒。用来支付真实业务成本，按卡的正式账单资料填写；保存软件、广告、服务器等支出的凭证。

**验收：**合法入金可用；如有实际所需的业务订阅，首笔正常消费及后续续费分别核对。公司卡不自动成为个人消费账户。

### 第 8 步：单独激活 Stripe Payments

1. 核对公司注册地区、业务类别和实际情况的适配；Stripe 全球支持名单包含美国、香港、日本等，当前标准商户支持名单没有中国大陆，不能把官网有中文版视为大陆主体可直接开标准账户。[全球支持地区](https://stripe.com/global)
2. 以实际符合资格的公司资料完成 Payments 激活，不以服务器位置选择经营主体地区。
3. 提交产品、与公司的关系、代表人及页面要求的资料；处理待验证项。
4. 设置对客户展示的名称、客服、网站及账单描述，便于客户辨认扣款。
5. 开启安全验证并保护 API 密钥。Stripe 推荐通行密钥/安全密钥，短信作为最后选择。[账户设置与安全](https://docs.stripe.com/get-started/account/set-up)

**验收：**生产收款权限和 payout 状态分别检查；没有未处理的限制通知。仅能进入 Dashboard 或创建产品不等于可以正式收款。

Atlas 公司可以按其官方流程申请部分前置收款功能，但 Atlas 本身不保证 Payments 最终通过。[Atlas 审核边界](https://docs.stripe.com/atlas/signup)

### 第 9 步：连接企业银行账户

从 Mercury 正式账户详情取得**对应收款方式**的账户号码、routing number 和账户持有人名称，在 Stripe 的 Payout 设置中配置，并按要求完成验证。不要把银行卡号填作银行账号，不要混用 ACH 和 wire 的路由资料。

匹配主体与币种；需要外汇或替代结算账户时，按 Stripe 与该金融机构的规则另行核对。[Stripe Payout 设置](https://docs.stripe.com/payouts)

**验收：**保存银行验证结果；生产环境的首笔真实销售后，必须实际看到 payout 入企业银行流水，才能记为“提现链路打通”。

### 第 10 步：创建收款页面，先做沙盒验收

入门方案可用 Payment Links：进入 Dashboard 的 Payment Links，创建或选择产品，设置一次性价格/订阅价格，生成链接；按业务设置客户信息、交付与售后。涉及订阅，还要核对 Billing 等产品费率。[创建支付链接](https://docs.stripe.com/payment-links/create)

按照第 10 节完成沙盒的成功、失败、认证与退款测试后再上线。线上付款成功回跳页不应单独作为自动发货证据；有系统集成时核对平台真实付款状态并避免重复交付。

**正式闭环：**独立真实客户付款 → 实际交付 → Stripe 交易记录 → payout → 银行到账 → 会计对账。

Stripe 官方说明首笔真实收款后的首次 payout 通常需要 **7–14 天**，还受行业、经营地区与风险水平影响。以你的 Dashboard 预计时间为准，不承诺当天到账。[Payout 时效](https://docs.stripe.com/payouts)

## 7. 路线 D：资金回国的实操边界

### 7.1 先填这张表，再挑通道

| 需要确定的项目 | 示例 |
|---|---|
| 钱是谁的 | 美国 LLC 的营业款 / 中国公司出口款 / 本人合法工资 |
| 钱是什么性质 | 货物收入 / 软件服务收入 / 真实服务费 / 利润分配 / 借款偿还 |
| 国内谁接收 | 合同中的中国公司 / 合资格商户本人 / 员工本人 / 股东本人 |
| 什么证据能解释 | 合同、发票、订单、交付/物流、股权与分配文件、税务资料 |
| 谁确认可受理 | 实际收款银行或所选持牌平台，明确对应产品和资料要求 |

“美国公司和我都是自己的”不是将公司营业款按个人日常汇款申报的理由。款项性质决定需要什么文件与处理方式。

### 7.2 不同业务的路线

**出口货物商户**

核对万里汇/Airwallex 等通道的主体与收款人要求 → 完成店铺授权、订单与出口背景资料 → 审核结汇/付款资格 → 提交合法实际款项 → 国内到账对账。

Airwallex 当前公布的人民币本地付款场景，包括 B2C 跨境电商、线上小额 B2B、线下 B2B 贸易，并要求对应商品从中国出口；收款人范围也有具体要求。[官方范围](https://help.airwallex.com/hc/zh-cn/articles/4633986370447-如何向中国境内付款)

**SaaS、数字产品、咨询或其他服务收入**

先拿真实合同和履约说明，向收款银行/平台说明准确业务类型、境外付款主体及国内接收主体，确认服务贸易或对应合法收入路径。不要拿货物贸易订单伪装数字服务，也不要仅因能绑定 Stripe 就推断能结汇。

**美国公司对国内支付服务费、工资、利润分配或偿还款项**

每一种性质分别核对真实法律关系、价格/金额依据、公司授权、必要的登记/税务材料、银行申报要求和可能的扣缴义务。获得具体受理结论后再转款；不人为编造“咨询费”作为统一出口。

以上两类服务/分配路线是待逐案确认的框架，**本次没有证明适用于你的特定主体组合**。外汇局要求金融机构对交易单证真实性及主体、金额、性质的一致性进行合理审核。[外汇局官方问答](https://www.safe.gov.cn/safe/2019/0701/13551.html)

### 7.3 首笔到账核对

对一笔符合批准用途的实际款项，记录：境外付款金额与币种、各项费用、汇率、预计到账、实际到账、银行申报记录。不得为了绕过审查把大额资金拆成小额。

境内个人购汇应真实申报；不得借用或出借额度分拆购汇，便利化额度也不赋予所有资本项目自由汇出权。[外汇局个人业务说明](https://www.safe.gov.cn/safe/2021/0402/18672.html)、[官方个人购汇申请书](https://www.safe.gov.cn/beijing/file/file/20210409/b31f1a9df3b24565a97cb6bc13dba26a.pdf)

## 8. 电话、VPM、服务器和 Claude：哪些要配，哪些不能承诺

### 电话号码

只在目标开户/服务流程确实要求时配置本人可长期控制的号码。原图“紫卡”型号未知；若考虑 Ultra Mobile PayGo，官方当前基础方案是每 30 天 $3，支持语音/短信漫游，额外漫游从钱包余额扣除，没有数据漫游。官方说明欠费后达到取消条件可能丢失号码。[Ultra PayGo](https://www.ultramobile.com/paygo/)

购买前确认具体 SIM/套餐、所在地是否能首次激活、手机兼容性、当地漫游与验证码接收情况。这些实际条件本次未测试；不能承诺“大陆直接激活”“所有银行验证码必达”。配置后分别验收普通短信、目标服务验证、续费及账号恢复。

### VPM 地址

VirtualPostMail 当前有普通 Virtual Mailbox，也有 TruLease 等不同产品。前者用于邮件接收/扫描等，后者宣传租约和地址证明；两者不能混称一种“美国地址”。[VPM 官方产品说明](https://www.virtualpostmail.com/)

先确定要解决的是接收 EIN 信件、法律地址、邮寄地址还是实际经营地址，再核对接收机构是否接受对应服务。地址供应商对“可开户”的宣传不能替代银行审核；不得申报虚假的实际办公或居住事实。

### 服务器与网络

服务器用于托管网站、软件和业务；本人设备、邮箱、验证器及安全登录用于控制账户。是否需要美国服务器取决于业务部署，不是银行开户的通用前置条件。

住宅 IP 至多是连接环境的一项特征。没有官方依据证明它能解决真实地区限制、企业控制关系审核，或确保账号不被关闭。稳定网络也不能使虚假身份资料成立。

### Claude 单独判断

1. 当前官方支持列表中有日本、美国等，未列中国大陆。先核对真实所在地，不通过公司注册地或网络出口代替。[支持地区](https://support.claude.com/en/articles/8461763-where-can-i-access-claude)
2. 官方要求付款方式的账单地址及来源国家符合支持条件，地址匹配发卡行记录，必要时完成 3DS；网页付款不支持 PayPal/Venmo。[付款规则](https://support.claude.com/en/articles/9402418-why-was-my-card-declined)
3. Anthropic 的 2025 年公告对受不支持地区控制的企业/组织另设限制，包括被总部位于不支持地区的公司直接或间接持有超过 50% 的实体。不能仅凭美国注册证绕过这一判断；也不能将该企业条款简化为“中国国籍个人一律不能用”。[企业限制公告](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)
4. 真实情况无法从条款确定时，向 Anthropic 官方说明具体所在地、主体与控制结构，保留答复。图片作者的个人未封号经历不是对其他人的保证。

### 9.2 特拉华 $300/$400 冲突怎么处理

本次直接读取时，部分旧官方 FAQ、法典汇编页面和 Atlas 税务说明仍出现 $300。继续追查后，州议会 HB400 页面显示 **2026-05-21 已签署**；已颁布法律第 23 条将 LLC 年税改为 $400，第 45 条规定该税款变动从 **2026-01-01** 生效。最新缴税专页同样写 $400。

因此，本手册对 2026 税年采用 $400；2026 年成立的普通 LLC 于 2027-06-01 支付首年税。不能把 2026-06-01 对 2025 税年的旧款与 2026 税年的新费混为一谈，也不能继续依赖旧教程。

依据：[州议会 HB400 状态](https://legis.delaware.gov/BillDetail/143069)、[已颁布法律第 23、45 条](https://legis.delaware.gov/json/BillDetail/GenerateHtmlDocumentSessionLaw?docTypeId=13&sessionLawId=143069&sessionLawName=chp273)、[缴税专页](https://corp.delaware.gov/alt-entitytaxinstructions/)。

### 9.3 一个可复算的预算示例

若采用 **Atlas + 普通 Delaware LLC + Mercury 基础账户**：

- 成立时固定已知费用：$500。
- 为 2026 税年预留州年税：$400，2027-06-01 缴纳。
- 因此，首个成立与税年周期至少预留 **$900**，尚未包含税务服务、地址、号码、服务器、交易费和任何所得税。
- 第二年起已知固定代理及州年税合计 **$500/年**，其他成本另加。

这不是“$900 包干完成全部业务”的报价，也不是都要在注册当天支付。

一笔 $100 的标准付款，仅看上述 Stripe 处理费示例：美国本地卡为 $3.20，到账处理前净额 $96.80；国际卡且不兑换为 $4.70、净额 $95.30；若再触发 1% 兑换费为 $5.70、净额 $94.30。未包含其他产品费、退款、争议、转款及税费，实际以账户合同和账单为准。[Stripe 费率](https://stripe.com/pricing)

### 9.4 持续维护不能遗漏

- 建立公司独立账簿，记录销售、退款、手续费、业务支出、出资、借款、分配和所有人与公司之间的交易。
- 外国所有的美国单成员 LLC，若按 disregarded entity 处理并有应申报关联交易，可能需要 **Form 5472 + pro forma Form 1120**；成立出资和分配等也要评估，不是只看是否有营业收入。
- IRS 官方规定，未按要求提交 5472 的初始罚款可达 **$25,000**，持续不报还可能追加。是否应报、截止日和延期按实际税年与实体情况确定。[IRS 5472 指引](https://www.irs.gov/instructions/i5472)
- C corporation、多成员 LLC、雇员、美国州内活动、销售税/VAT和所在地税务另行适配，不以“美国 LLC”直接推断全球免税。[Atlas 税务范围](https://docs.stripe.com/atlas/business-taxes)
- 当前 FinCEN BOI 官方页面已说明，美国成立的公司豁免该项 BOI 报告，2026 最终规则已生效；**这不取消银行受益人 KYC、IRS 或州申报义务**。外国成立后登记在美国经营的实体不能直接套用同一豁免。[FinCEN BOI](https://www.fincen.gov/boi)
- 不再经营时，正式处理注销、最后申报和剩余责任。关闭 Stripe 或停止注册代理扣费不等于公司依法注销。

## 11. 常见失败：按证据排查

| 现象 | 优先检查 | 下一步 |
|---|---|---|
| 国内信用卡在海外商户失败 | 商户地区/卡组织规则、发卡行限制、地址、额度、3DS | 保存失败码，联系发卡行/商户；避免连续重复刷卡 |
| PayPal 关联卡成功但不能付款 | 商户是否接受、资金来源、交易币种与账户限制 | 关联成功和交易成功分别判断；Claude 网页不支持 PayPal |
| Wise 有余额功能但没卡按钮 | 发卡地区和实际住址资格 | 按真实情况用其他合资格方式，不改成虚假海外地址 |
| Mercury 要求补地址 | 法律地址与实际经营/受益人住址混用 | 按对应字段提交真实可验证证明 |
| Mercury 未通过 | 业务/地区/资金来源/美国经营计划是否符合要求 | 根据正式反馈补充可验证资料，不买包装身份 |
| Atlas 成立但 Stripe 受限 | Payments 独立审核、业务类型、资料完整性 | 处理具体待验证项；成立费用与持续义务不会自动消失 |
| Stripe 有销售额但银行没收到 | pending/available、payout 状态、初始等待期、银行详情 | 以 payout 记录与银行流水核对，不把销售额当可提现余额 |
| World Card 有卡但扣款失败 | 可用币种余额、额度、3DS、商户接受范围 | 按失败原因处理，不靠虚假自买创造余额 |
| 资金不能结汇回国 | 款项性质、订单额度、主体、出口/履约背景和申报 | 暂停该转款，取得实际接收银行或平台的具体受理条件 |
| Claude 有美国卡仍不能用 | 实际支持地区、账单来源国、企业控制结构和账号规则 | 按官方原因处理；美国卡不是全部资格的证明 |

## 12. 按依赖推进，不许诺几天“全通”

### 第一阶段：先打通最小需求

- 写清“只买工具 / 收客户款 / 资金回国 / 融资”哪几项是必需结果。
- 先验收目标商户地区资格和现有付款方法。
- 有跨境经营时先拿到业务、主体及回国渠道的适配结论。

### 第二阶段：确需公司才注册

- 比较主体结构和年度成本；完成资料、网站与税务安排。
- 注册，等待税号；可以同时继续完善业务页面、交付和记账，不承诺税号两天取得。
- 按正式要求申请企业资金账户及收单服务。

### 第三阶段：先沙盒，再真实业务闭环

- 完成成功、失败、3DS、退款、必要的订阅测试。
- 上线真实业务，逐笔核对收款、交付和银行到账。
- 需要回国再验收对应的实际合法转款；未完成这一项，就保留“回国路径未验收”。

### 第四阶段：持续维护

- 每月对账，留存资金来源、合同及交付资料，保持客服与退款处理。
- 按实体税年设置州税、申报、注册代理续费和必要的所在地义务。
- 资料、所有权、住址或业务改变时更新正式记录。

**完成的定义：**需要的每条链路都有相应资格和实际验收证据。只有注册证或某张卡截图，不能称“支付、收款、回国都完成”。
