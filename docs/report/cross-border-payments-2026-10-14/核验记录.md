## 费用冲突的解决过程

1. 搜索发现 Delaware 官方资料分别出现 $300 和 $400。
2. 本机直接读取缴税页：$400；汇编法典页：$300。未凭多数投票取值。
3. 定位州议会 HB400，状态为 2026-05-21 Signed，章号 85:273。
4. 读取已颁布法律：第 23 条修改 LLC 年税，第 45 条规定相关税款修改自 2026-01-01 生效。
5. 与当前官方缴税专页一致，因此对 2026 税年采用 $400；2026 年成立的公司首笔于 2027-06-01 到期。

依据：[HB400 官方状态](https://legis.delaware.gov/BillDetail/143069)、[已颁布法律](https://legis.delaware.gov/json/BillDetail/GenerateHtmlDocumentSessionLaw?docTypeId=13&sessionLawId=143069&sessionLawName=chp273)、[当前缴税说明](https://corp.delaware.gov/alt-entitytaxinstructions/)。

## 如何更新

需要复核公开页面时可运行同目录《核验工具.py》；它依赖 Python 和 BeautifulSoup，只发起公开只读请求。如果遇到真实网络连接失败，只尝试已有配置的代理一次，不打印代理凭据；服务端 HTTP 拒绝则保留状态。

页面关键词检查是辅助证据，地区名单的含义、法律修改中的删除/新增、账户个案条件仍需要阅读原文，不能仅用字符串匹配自动作业务裁决。
