把人生当成一场 online 游戏

今天的主线不是“做了很多事”，而是明确了一个新的操作系统：主线负责赚钱和产出，支线负责链接、体验和机会。问题在于，今天主线推进一般，支线也太弱。

CORE INSIGHT

真正有价值的不是平淡过完一天，而是让每一天产生反馈。

SEO 站上线、室友代理、复盘习惯、麦克风纠错、弱关系缺失，全都在指向同一个结论：行动之后必须有反馈，反馈之后必须改系统。否则一天只是过去了，没有变厚。

MAP

三个主判断

01 / MAIN

主线要守住高产时间

SEO 站已经上线，但 `9:00-18:00` 被消息切碎。以后高产时间必须围绕主线任务，消息和碎片输入放到低能量窗口。

02 / SIDE

支线不是娱乐，是机会网络

今天遇到很多人，却几乎没有建立任何链接。弱关系被拒绝的成本很低，但成功收益可能很高，支线需要主动触发。

03 / SYSTEM

习惯不能绑死在工具上

录音豆坏了就换手机，日醒没跑就补确认。工具是增强器，不是习惯的单点故障。真正断更的是惰性，不是设备。

RULE

可复用方法

expected value

期望值决策

不要只看成功概率。看成功概率乘以成功奖励，再减掉失败概率乘以失败损失。期望值为正，就可以小成本试。

reversible

可逆决策快跑

可撤回、可边做边改的事，尽快跑闭环。不可逆、重资产、长期绑定的事，才慢慢评估。

execution

制度降阻力

老板不能只管决策。推新制度时，要给执行者过渡动作，不忙时复制文字，忙时先截图，先让流程动起来。

attention

动作激活状态

读不进去，就读出来。注意力不是等来的，很多时候需要用身体动作把它拉回现场。
