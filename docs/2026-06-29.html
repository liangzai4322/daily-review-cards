CORE INSIGHT

今天真正沉下来的东西

你现在的问题不是不复盘，而是复盘之后没有强制进入迭代闭环。

GAP 教练的价值，是把问题从日省里拎出来继续追问。生活飞轮的价值，是让问题不再靠情绪临时处理，而是进入触发、运转、结束、验证的系统。

ARGUMENT MAP

六个主模块

01

GAP 教练重启

普通复盘会把问题记下来，GAP 教练会继续追问为什么、怎么避免、细化到什么程度才算合格。它补的是你自己问自己不够深的环节。

02

三层迭代节律

天负责纠偏动作，周负责提炼归类，月负责验证结果。每天的迭代必须有出口，否则日省只是文本堆积。

03

生活飞轮系统

复盘、规划、执行、健康、学习都可以做成飞轮。正向飞轮降启动摩擦，负向飞轮升启动门槛。

04

峰终定律戒抖音

刷抖音不是靠骂自己解决，而是利用记忆机制，让坏习惯的峰值体验和结束体验都变差。

05

系统管理团队

段永平经销商体系的启发是，老板不要无限拍板，要设计排名、价格、营销资金和替换机制，让体系自己跑。

06

小红书勤换品

朋友的真实样本说明，只坚持发还不够，还要持续换品。起步时先像素级模仿爆款，保住商业下限。

FLOW DESIGN

从复盘到操作系统

capture

每日随手记，统一进入入口。不要让素材散在多个地方，先保证可被看见。

review

晚上复盘，不只安排明天任务，还要找今天做差的地方。

gap

把最卡的问题交给 GAP 教练单独追问，逼它从情绪变成规则。

principle

当天结论进入原则库，周末提炼归类，月末回看是否真的改掉。

MEMORY HOOKS

金句锚点

“复盘的意义是什么呢？是要改进的呀。”

这是今天最高权重的判断，复盘如果不改进行为，就只是记录。

“你怎么把今天存成一张卡片呢？”

日省卡片不是仪式感，是把今天变成证据。

“没有规划，你的规划就会被世俗的规划带着走。”

没有主动设计，默认路径就会自动接管人生。

ACTIONS & RISKS

下一步不能停在“想通了”

明确动作

  • 1SEO 站先明确核心功能边界，2-3 天内只追“能用”，技术排行榜后置。
  • 2小红书虚拟资料拿出完整一小时，打开行业手册，边研究边实操。
  • 3GAP 教练继续保持频率，把当日卡点拆成原则和具体改法。
  • 4五谷磨房粉和录音豆已到，分别接入饮食系统和录音系统。

行为风险

  • !对新朋友接纳度仍低，记名字和开放邀约还需要主动练。
