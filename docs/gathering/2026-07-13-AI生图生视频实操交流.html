Meeting Overview

这场交流最值钱的，不只是生成了一张图。

现场最有价值的部分，是把一条看起来简单的 AI 内容链路拆回现实。模型要成本，Skill 只是流程说明，API key 是访问凭证，供应商会失效，免费积分也会用完。真正要落地，还得处理网络、权限、目录、参考图、提示词和业务场景。工具演示只是第一层，稳定工作流才是终点。

01COST

生成成本先决定场景，再决定模型

Harry 提到，「1080P 这种分辨率，大概要 15 块钱，15 秒的视频，还是比较贵的。」这句话给整场实操定了一个现实边界。图片和视频不是同一种成本结构，文生图可以借助免费产品或新用户积分低成本验证，视频一旦追求高清、时长和动作质量，算力成本会快速上升。

现场因此没有直接选择昂贵方案，而是尝试低成本 API 和开源或自建服务。这里的判断不是哪个模型最强，而是当前业务验证需要什么质量、能承受多少单次成本，以及失败时是否值得重做。

02RESILIENCE

模型供应链必须准备 Plan B

Harry 提到，「正常去落地做这个事情的时候，一定要想到一个 Plan B。」他担心 GPT 相关能力可能被封、供应商随时失效，因此把模型平台看成供应链，而不是永久基础设施。就像找供应商不能只有一家，内容工作流也不能把唯一入口押在一个 API 上。

主模型失效时，替代模型能不能在一天内接管，才是工作流是否成熟的检验。

这个原则当天就被验证。第一个网站没有按预期发放积分，key 也无法正常调用，现场只能切换到另一个平台和另一套 Skill。Plan B 不是预防性口号，而是实际救回了课堂进度。

03PEOPLE

八个人带来了八种 AI 落地入口

Harry 提到，「先介绍自己，最近做一些事情，包括用三到四个标签，让别人方便链接你。」现场成员覆盖就业陪跑、计算机代做、银发食品、公司运营、小红书虚拟产品、亚马逊运营、跨境电商服务、家居获客与剧本代写。大家对 AI 的需求并不相同，有人要降低公众号运营成本，有人要批量二创，有人要做带货视频，也有人还在寻找第一个业务切口。

这张业务地图提醒大家，生图生视频不是一个独立赛道。它可以是获客素材、交付环节、产品功能，也可以只是内部提效工具。脱离业务标签讲模型，参与者很快就会陷入只会生成、不会使用。

04AUTOMATION

公众号七篇周更，从两三小时压到十分钟

Harry 提到，「之前一个星期大概要花两三个小时，写出大概七篇文章，现在投入的时间大概一个星期五到十分钟。」他的就业陪跑业务由一个人完成运营、产品与销售，客单价约四千元，公众号成为最适合先自动化的重复环节。

他还提到，在一个由 AI 辅助写作的月份里，公众号约涨粉两千。这里真正跑通的不是让 AI 随便写，而是模板化生产、人工 review 与扫码发布的组合。人的工作从写初稿转为审核事实、判断表达与承担发布责任。

05PLATFORM

模板会衰减，异常 IP 也会伤害分发

Harry 提到，「大概一个月的话，模板估计要变更。」标准化文章虽然节省时间，但平台可能识别长期重复的结构，读者也会对相同节奏产生疲劳。因此自动化不是模板一次写完永久运行，而是把模板轮换、数据观察与内容抽检一起做成维护周期。

他还复盘了使用美国 IP 操作公众号后台后阅读量下降的经历，并将其理解为平台风控或分发影响。该因果关系在现场没有独立验证，但足以形成操作风险提示，内容生成可以在海外模型完成，平台登录与发布应尽量保持稳定、可信的网络环境。

06OPERATION

龙伟把半小时的重复点击压到五分钟

龙伟提到，「以前可能需要手动点按、很重复的一些东西，后面直接用 AI 就可以实现。以前要半个小时，现在可能五分钟就搞定。」他的场景来自计算机代做业务，AI 的价值不是替代专业交付，而是接管机械操作与重复流程。

这也与他的 OPC 和自由职业标签一致。一个人承担多环节业务时，最先自动化的应该是频率高、判断少、步骤稳定的动作。节省下来的二十五分钟，只有重新投入获客、成交或质量控制，才会变成业务收益。

07SILVER

银发内容的难点不是产量，而是新鲜表达

广度提到，「从 21 年开始做银发赛道，中老年食品，从抖音到快手到视频号，一直在做矩阵。」他的商品包括书和养生品，已有成熟渠道，但旧内容越来越泛，缺少新颖度，关注效果也在下降。

他来学习 AI 文案与视频，不是因为没有内容经验，而是希望给成熟矩阵增加新的视觉表达。对这类业务，AI 的合理角色是扩大创意测试量、降低视频试错成本，但健康和养生表达仍需要更严格的事实审核，不能用生成效率替代合规判断。

08CONTENT OPS

小红书二创已经从采集走向本地知识流

小彭提到，「自己做了小红书插件，可以采集小红书上的爆款，之前同步到飞书，后面采集到 Obsidian，再接 DeepSeek API 做分析。」她的工作流已经覆盖采集、存储、分析与二创，只是视频上传与视频生产仍是空白。

这个案例说明，内容自动化的成熟度可以分层。采集和分析已经结构化，不代表创意和发布就应该全自动。她仍保留部分手动二创，是因为平台适配与选题判断需要人介入。本次生图生视频实操，正好补的是现有链路中缺失的视觉生产环节。

09VOICE

知识库的价值，是让甲方仍然像甲方

西米提到，「用 Obsidian 加 Codex，给我还有甲方搭了一个知识库，可以按照我们自己的表达形式去输出，甲方也挺满意。」她负责把甲方公众号内容适配成小红书，而不是简单爬取同行后批量改写。

现场有人追问为什么不直接抓同行内容，她解释甲方有自己的想法，目标是卖自己的社群。这里的关键不是生成更多文章，而是保留主体表达、完成平台迁移。知识库只有能稳定取回原有观点、案例和语气，才真正减少沟通成本。

10PRODUCT

从家居效果图工具，到公司内部 AI 转型

阿杰提到，「开发了一个自己的小程序，直接拍一张照片，就可以生成效果图。」他原本做家居直播与短视频获客，试图把生成能力嵌入线下转化链路。产品尚未上线，自媒体也只有部分流量，因此当前更像一项待验证的业务能力，而不是成熟产品。

他同时准备在公司内部分享广告投放部门如何结合 AI，帮助同事提升认知、降低恐惧。对企业转型而言，现场跑通一个岗位模板通常比讲模型趋势更有效。员工需要看到自己的任务如何缩短，而不是再听一遍 AI 会改变世界。

11INFRA

Skill 是流程，API key 是访问凭证

Harry 提到，「你光有 Skill 是不行的，你还得有 API key，API key 可以理解是一个权限。」现场多次出现装好 Skill 却无法生成、拿到 key 却不知道放在哪里的情况，说明这两个概念对新手并不自然。

Skill 告诉 Codex 怎么做，API key 允许它去调用谁。两者都不等于免费额度。

更准确地说，Skill 封装调用步骤、参数和输出约定，API key 用于识别账号及授权请求。模型平台、Skill 与业务文件三者应该解耦，这样替换供应商时，只改调用层，不必重做整个项目。

12ECONOMICS

新用户积分不是免费算力

阿杰提到，「API 只是一个调用的接口。免不免费，不是接口决定，而是新用户给你送一些积分。」这段反复解释很有价值，因为参与者一度把 key、免费资格和调用次数混在一起。

图片和视频背后都消耗算力与电力，平台只是用赠送积分降低首次体验门槛。做业务预算时，不能按注册当天的零成本估算长期毛利，应该记录每次生成的积分、成功率、重试次数与最终可用率，再计算一条成片真正花了多少钱。

13SECURITY

完全访问权限能提速，也会扩大误操作半径

龙伟提到，「有个完全访问权限，但如果电脑里面有重要数据，不太建议开。」现场为了减少 Codex 每一步都询问授权，参与者寻找完全访问设置，但同时提到自动删除文件的风险传闻。

该具体事故在会议中没有核验，不能当成事实引用，但安全原则成立。全权限应该只在隔离目录、明确任务和可恢复备份下使用。新手第一次操作时，频繁确认虽然慢，却能帮助他看清工具正在读什么、写什么、删什么。

14LAB

第一次生图，真正卡住的是调用链

Harry 提到，「先验证一下链路通不通，能不能生成图片和视频。」现场先安装图片 Skill，再配置 key、指定 Skill 和提示词。第一个平台因积分或服务异常无法使用，随后切到新平台重新注册、重新拿 key、再装另一套 Skill。

参与者最终生成了图片，但速度和结果存在差异。整个过程反复卡在代理网络、谷歌登录、Skill 名称、key 配置、权限弹窗和平台额度上。它提醒教学者，演示成功不等于学员能复现，现场课程必须准备统一环境检查表、备用 key、备用平台和一页式操作路径。

15MOTION

同一句提示词，也可能生成不同动作

董丽提到，「他的路飞手会动，我的不会动，我提示词就复制你那个。」现场有人生成的人物动作更明显，有人画面几乎不动。大家推测与模型档位、参数或随机性有关，也发现忘记附参考图时，模型无法按预期生成。

Harry 还提到，同一个会话里可以利用上下文记忆，从已生成的角色继续做视频；现场方案单次最多生成约五秒。要稳定复现，不能只保存一句提示词，还要保存参考图、模型、档位、时长、尺寸与随机结果，最好连失败样本也一起记录。

16WORKFLOW

女装带货案例从目录开始，而不是从提示词开始

Harry 提到，「我们新建一个目录，女装，再建一个模特文件夹。」在演示效果后，现场准备从模特照片出发，生成白底图与后续视频，并让 Codex 进入指定项目目录。这个动作看起来基础，却决定了参考图、生成结果和后续版本能否被稳定找到。

转写在模特文件刚放入项目、准备继续处理时结束，因此只能确认案例已经启动，不能确认白底图、带货视频或完整交付已经跑通。后续若要复盘这条工作流，需要补齐输入素材规范、目录结构、提示词版本、成片结果和单条成本。

记录边界

本总结只依据 2026-07-13 的飞书妙记转写。模型名称存在语音识别误差，部分平台与事故说法未独立核验；涉及“约 2000 粉”“一天 100 张”“完全访问权限删除文件”等内容，均按现场经验或估计记录，不视为通用事实。转写在女装案例进行中结束，未记录最终产物。
