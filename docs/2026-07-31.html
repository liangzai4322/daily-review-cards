02

从“面板搭出来”切换到“任务流得动”

主参谋面板的价值不是好看，也不是接了多少系统。输入能进入盒子、任务只有一份、完成证据能回流，才算打通。否则只是在不同页面重复维护同一件事。

03 / OPERATING SYSTEM

四条可以复用的行动规则

RULE 01 / 买伞法则

先问多少钱能买掉这个障碍

比较解决成本和继续卡住一小时的成本。低成本、可逆、能立刻恢复行动的问题，优先直接解决。

RULE 02 / 书包丢墙外

先做一个无法忽略的第一步

出门、发第一条消息、打开数据目录。第一步不是完成任务，而是把问题从想象变成真实反馈。

RULE 03 / 闭环验收

只用真实任务验证系统

检查任务能否正确进入日期页和盒子，完成后证据能否回流，重复执行是否只更新而不复制。
