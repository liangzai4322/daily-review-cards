书籍分享：《有钱人和你想的不一样》

分享者：欧欧（说话人5）
💰 财富思维
  • 核心理论：财富蓝图——一个人能赚多少钱，取决于其内在对金钱的想法、感觉与行动
  • 三种制约方式：语言设定（小时候听到了什么）、模仿（看到了什么）、特殊事件（经历了什么）
  • 外在财富是内在思维的投影，改变果实必须从根上改变
  • 书中对比了17组穷人思维与富人思维的行为差异
  • 欧欧个人案例：母亲的匮乏感语言设定导致她成年后的月光族行为
  • 改变路径：审视错误金钱观的来源 → 评估欲望的真实性 → 延迟享受 → 财务状况好转

欧欧提到，"这本书特别好看"，核心观点是"想要改变果实，必须要从根上开始改变，想要改变我们看得见的东西，必须要改变我们看不见的东西"。她详细介绍了财富蓝图的形成机制：内心设定导致想法，想法产生感觉，感觉驱动行动，行动决定结果。

欧欧结合自身经历深入剖析：母亲长期重复"家里没钱"的语言设定，让她幼年形成了压缩欲望的习惯，成年独立后却走向了另一个极端——"我不要像我母亲一样老是说没钱，我有钱了我就要用掉"，由此成为月光族。读完这本书后，她开始主动追问每一次消费冲动背后的真实需求，学会延迟享受，财务状况与内心状态均有明显改善。

她推荐这本书的原因在于，它提供了一套分析框架，帮助人们找到金钱观中的卡点——"不会再掉进同一条河里两次"。对于那些赚到一定钱后反复陷入瓶颈、成功后又归零的人，这本书尤其值得一读。

书籍分享：《小狗钱钱》

分享者：思敏（说话人6）
🐾 理财入门
  • 核心概念一：下金蛋的鹅——积累资产形成被动收入，覆盖日常支出，实现财务自由
  • 核心概念二：笼子里的老鼠——被债务和固定支出逼迫不停奔跑，无法停下思考
  • "养鹅计划"三要素：主业（提高收入上限）、投资（钱生钱）、理财（资产增值）
  • 投资心得：投资陌生行业有风险；投资本质上是投人，选择靠谱的人比选择项目更重要
  • 赚钱的阶段论：0到1赚第一桶金 → 规模化 → 资产增倍（投资理财）

思敏分享了这本儿童与成人皆宜的理财读物，重点围绕两个动物意象展开。"下金蛋的鹅"代表能持续产生被动收入的资产体系——"把你的钱，不管是父母留给你的还是自己赚来的，去掉日常开销以外，能够慢慢累积起来，有一定资产之后形成被动收入"，当这个被动收入能够覆盖日常支出，生活的从容感便会逐步建立。

"笼子里的老鼠"则是另一种现实的写照：被车贷、房贷等固定支出追着跑，只要停下来就意味着断粮，根本没有冗余时间去思考更大的可能性。思敏以男朋友为例，说明这种状态如何让人失去选择工作的自由度。

受这本书启发，思敏辞去工作开始创业，并尝试了民宿投资等多个项目，积累了宝贵心得："投资什么，其实你是在投资人"——在自己熟悉的领域深耕，交几个靠谱的朋友互相投资，是她认为成功概率最高的路径。她也坦言自己目前仍在0到1的阶段，但已开始为未来的资产增值阶段提前布局认知。

书籍分享：《遥远的救世主》

分享者：吴常（说话人4）
🎭 人生哲学
  • 小说核心：丁元英帮助王庙村做格律诗音响，引发对商业规律与人性的深刻探讨
  • 刘冰的悲剧：把丁元英当作救世主，抓着一个纸袋幻想找到了依靠，最终崩溃
  • 丁元英的局限：只能给人进入市场的机会，却给不了承担市场风险的心智
  • 核心启示：没有真正的救世主，路要靠自己走；给不了我的，我也拿不住
  • 延伸思考：AI工具、优质社群、高人指点都可能成为人们寄托的"救世主"
  • 关联：AlphaGo第37手——看似败笔却是神来之手，强化学习超越人类语言模型

吴常分享了这部由豆豆所著、后被改编为电视剧《天道》的小说。他结合自身2008年从华为离职后的经历，谈到彼时"希望有一个高人指点，或者有个所谓的救世主，找到一个好的项目"的心理——这种心态其实在当下依然普遍，无论是加入某个社群、使用某款AI工具，还是跟随某位导师，人们往往在寻找一个"遥远的救世主"。

书中刘冰的悲剧最令吴常印象深刻：丁元英给了他一个纸袋，他便如同抓住了救命稻草，把这个袋子当作翻身的凭证。然而丁元英的本质是"只给进入市场的机会，却给不了承担市场风险的心智"，一旦遭遇商业风险，那些把他当神的人便感受到巨大的欺骗与恐惧。吴常由此感悟，"给不了我的，我也拿不住"，所有的经历最终都会成为自己要走的那条路，踏踏实实往前走才是根本。

书籍分享：《纳瓦尔宝典》

分享者：依琳（说话人1）
⚡ 注意力与杠杆
  • 核心观点：生命真正的财富是注意力，它取决于你选择关注什么以及如何对待它
  • 注意力的敌人：通勤时间、疲惫感、碎片化信息、无止境的情绪内耗
  • 普通人的杠杆：更近的住处、稳定的作息、定期锻炼——都是降低损耗的杠杆
  • 核心原则：不要比拼时长，要比拼杠杆；靠意志力硬扛对抗人性的事情不长久
  • 判断标准的转变：从"能不能省钱"到"能不能保护注意力、减少长期损耗"
  • 直觉有时比算账更早知道答案

依琳以一件生活小事引出这本书的精髓：她因公司离住处太远，每天通勤一个半小时，导致下班后精力全无，原本能做的短视频和私单都无法坚持。她"怒掏3000块押金"换了一套更近的房子，才发现多出来的不只是时间，更是"对一天的时间的掌控感"。正是这件事让她真正理解了书中那句话——"生命真正的财富是注意力"。

她进一步阐释了"杠杆"这个概念在普通人生活中的具体形态："一个离公司更近的住处是杠杆，一个稳定的作息是杠杆，一个每周能坚持一两次的锻炼，它也是杠杆。"很多时候我们努力的努力，却在路上被损耗抵消，靠意志力硬扛对抗人性的事情终究不长久。

依琳坦言，这本书没有帮她解决任何具体的现实问题，"房租依旧要付，生活的压力也不会因为几句话就消失"，但它改变了她的判断标准——从"这件事划不划算"，变成了"这件事能不能保护我的注意力、能不能让我每天多一点心力去做更重要的事情"。她最后引用书中的话送给大家："平静的接受生活中发生的一切，不带立场，不做评价，去找到那些最重要的人和事。"

分享者：三三（说话人2）
🌊 自我寻找

  • 别人的真理永远成为不了自己的真理；教义可传授知识，却不能替你活出人生
  • 终极领悟：世间万物本就圆满，全然经历、全然接纳，活在当下即觉醒
  • 对三三的影响：摆脱对间接经验的崇拜，勇于亲身尝试，接受所有弯路

三三在快要毕业时读到这本书，彼时她"从小到大永远都是处在一种非常焦虑的生活中，好像你初中就想着中考，高中就想着高考，永远有一个关卡好像永远没有办法停止"。悉达多的故事让她意识到，这种"永远在赶社会时钟"的状态，正是大多数人的困境。

书中最打动她的是那句"知识可以分享，智慧无法言传"。悉达多明白了别人的真理无法成为自己的真理后，毅然转身离开佛陀，选择坠入红尘去亲身经历。他经历了财富、情欲、名利，却依然痛苦空洞，直到在河边做了一名船夫，安静地倾听河水，才悟到"不用抗拒苦难，也不用逃避欲望，只要全然经历，全然接纳，活在当下就是真正的觉醒"。

三三将这种领悟映射到自己做小红书电商的经历上：看再多的精华帖，"还不如自己发100篇来的痛苦和实在"。当那些关于封面重要性、标题技巧的口号变成切肤体验，"被捶打了之后就整个人就会 peace 很多"，不再被数据蒙蔽双眼。这本书给了她勇气，告诉她"一切的经历都是值得的，都是必然的，是获得智慧必要的考验"。

书籍分享：《埃隆之书》

分享者：龙伟（说话人3）
🚀 使命与方法论
  • 马斯克成长：南非被欺凌的自闭少年 → 9岁读完家中所有书 → 17岁出走加拿大
  • 早期经历：锅炉工（时薪$18）→ 名校读书 → 创办Zip2卖出$3000万 → PayPal卖出$1.7亿
  • 关键转折：被合伙人踢出PayPal董事会，平静接受，全押SpaceX与特斯拉
  • 至暗时刻：1.7亿美元几乎耗尽，两家公司濒临倒闭，第四次火箭发射成功救活SpaceX
  • 现有五条业务线：SpaceX、特斯拉、脑机接口（Neuralink）、X（推特）、隧道公司（Boring）
  • 三大启发：热爱与使命感、第一性原理（不只知道怎么做，还要知道为什么）、五步算法（质疑→删除→优化→加速→自动化）

龙伟以"压轴"身份分享了这本由纳瓦尔汇编马斯克公开言论而成的书，他用一句话概括马斯克："这是一个在物理学、银行学的范围内，把不可能变成可能的那么一个人。"他梳理了马斯克从南非被霸凌的少年、到锅炉工、到互联网创业者、再到火箭与电动车先驱的完整人生轨迹，尤其着重描述了那个"至暗时刻"——手里只剩4000万美元，两家公司都快死掉，却做出了"两个都不死"的决定，各投2000万。

龙伟最受触动的是三点：第一是热爱与使命感，马斯克在任何一个节点都可以放弃，但"让人类移民火星是我的责任，是我的热爱，是我的使命感"，这让他有了无限的动力；第二是第一性原理，"我不仅要知道怎么做，我还要知道为什么"，这也是他现在与AI对话时最常用的框架；第三是五步算法，尤其是"删除"这一步——"我发现我们大部分的时候东西太多了，但是我们需要把它删掉"。

他以纳瓦尔的话作结："你不必做埃隆做的事，也不必用他的方式去做。但是在你这短暂的一生中，最好花在竞技场上，花在某件超越自我的事情上面，拒绝舒适和认可，渴望回到年轻时的乐观，离开那些只会说话和制造分裂的人，走上学习和建造的道路。"

问题讨论：做自媒体最大的卡点是什么？

由吴常提出，全员参与讨论
  • 最普遍的卡点：想得多，就是没有开始第一步
  • 龙伟：完美主义——觉得内容必须足够好才发，导致一直没发；后来强迫自己发了一篇"垃圾"，跨过了那道坎
  • 龙伟：选题困难，不知道写什么；方向是做着做出来的，不必提前想好垂直领域
  • 欧欧：自媒体要从利他角度出发，想清楚能给目标受众提供什么，而非纯粹自我表达
  • 欧欧：要有强大的心脏，不在乎负面评价；黑子也是帮你增加流量的机器
  • 三三：公众号过100粉丝后有分成收益，哪怕几分钱也能形成正反馈，极大提升坚持动力
  • 三三：成长日记式内容最容易做，每周复盘自己在做的项目，真实暴露数据，别人愿意看
  • 依琳：ENFP特质导致账号多而不精，有正反馈的账号才能长期坚持
  • 共识：自媒体是普通人最大的杠杆之一，开始比完美更重要

吴常提出这个问题，是因为他认为"这个时代最大的红利就是自媒体"，只要开始做，多做少做都会有收获。讨论中最高频的答案是"还没开始"——龙伟的卡点尤为典型，他长期觉得内容必须做得非常好才值得发出去，结果一直没发；直到某天强迫自己发了一篇"垃圾"，才算真正跨过了那道心理门槛。欧欧指出，卡点的另一面是在发布之前就开始评判自己的内容，而没有经过市场验证，"你的想象只是想象而已"。

欧欧从2015年就注册了公众号，积累了丰富的自媒体经验。她强调，做自媒体的核心是从利他角度出发，想清楚能给受众提供什么，而不是站在自己的角度想表达什么。她还分享了心态建设的重要性：同样的内容发在小红书大家觉得有共鸣，发在公众号却可能招来一群喷子，"受众不一样，不要太在乎别人的评价，自己心脏大一点"，甚至可以把黑子当作增加热度的工具。三三则补充，公众号超过100粉丝后的分成收益虽然可能只有几分钱，但那种"只要写了就有钱"的感觉会让人上瘾，是坚持下去的重要正反馈。

问题讨论：如果一个月后离世，你会做什么？

由吴常提出，引发关于"向死而生"的深度探讨
  • 吴常：每天活得像明天就会死，这种心态已坚持10年，源于读《相约星期二》的感触
  • 吴常：目前继续做AI视频与工具打造，生命无常，每天做好当下就是答案
  • 三三：把这个问题当成游戏设计——一个月后游戏结束，现在怎么玩？
  • 三三：会邀请10位家人/朋友/网友，每人分配1—3天，密集实现他们的愿望，录成视频留给世界
  • 思敏：曾写过遗愿清单，更多是为了梳理"做了哪些事情不会留遗憾"
  • 思敏：想写一部类似自传的东西，哪怕只影响到一个人也好
  • 依琳：遗愿清单包括：探索世界、个人成长、找到志同道合的人、拥有自己的事业
  • 玉玲：这个问题的本质是"向死而生"——思考死亡，是为了更清晰地知道自己真正要什么

这道问题由吴常写出，被其他人调侃为"务虚"，却引发了全场最真实的一轮分享。吴常说他"每天不是想着一个月以后，我是想着明天就带的这种感受"，这种"随时可以死掉的感觉"已经伴随他超过十年，源于早年读《相约星期二》的触动。他认为每天把当天过充分，就不会后悔这一生，因此对于"一个月后会做什么"，他的答案是：继续做现在每天在做的事情。
