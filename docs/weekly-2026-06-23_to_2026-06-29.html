5WHY ROOT CAUSE

三个卡点，根因都不是“懒”，而是系统封口没做好。

小红书虚拟为什么拖？

  • 卡在“不知道上什么品”。
  • 默认先想产品，再验证市场。
  • 把创新放在起点，低估像素级模仿。
  • 没有固定时长和验收标准。
根因：把探索当脑内决策题，而不是低成本实验题。

复盘为什么曾经低效？

  • 记录很多，但原则产出不稳定。
  • AI 整理会制造“已成长”的错觉。
  • 文本归档没有自动变成行为纠偏。
  • 缺少周归类和月验证出口。
根因：复盘链路停在文本，没有进入原则生产系统。

短视频为什么停不住？

  • 状态失重后大脑寻找高刺激补偿。
  • 多巴胺基线升高，普通工作更痛苦。
  • 积分系统没有绑定入口和惩罚。
  • 环境中有人刷，自己也被触发。
根因：把高刺激当自控问题，而不是负向飞轮问题。

FLYWHEEL SYSTEM

本周最该保护的，是这些正在形成的循环。

正向飞轮

  • 每日记录 → AI 整理 → GAP 追问 → 原则入库 → 周省归类 → 月度验证
  • Codex 执行 → 外部可见资产增加 → 更愿意分配重复任务 → 产能放大
  • 手把手教学 → SOP 沉淀 → 代理执行 → 老板退出低价值消息处理
  • 目标显化 → 早晨输出 → 产出反馈 → 目标继续清晰

负向飞轮

  • 琐事打断 → 状态失重 → 刷短视频补偿 → 基线升高 → 工作更痛苦
  • 主动刷消息 → 状态浮躁 → 主线碎片化 → 焦虑上升 → 继续确认消息
  • 目标模糊 → 行动拖延 → 挫败感上升 → 想更多方向逃避执行
  • Codex 跑任务 → 人等待刷手机 → AI 并行退化为串行
