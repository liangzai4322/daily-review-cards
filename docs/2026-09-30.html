03

Execution pattern

最大的泄漏，不是没目标，而是入口失控

  1. 知道要做什么

    目标感并不弱，三个账号与视频方向都很清楚。

  2. 从工作入口进入娱乐平台

    打开 B 站原本为了研究或养号，却被短视频带走注意力。

  3. 把执行问题改写成意义问题

    从“不想做”转向追问野心、动力与为什么做，绕开眼前动作。

  4. 重新回到制作并完成交付

    一旦进入脚本、录制与剪辑链路，任务就重新开始前进。

新的执行规则

打开 B 站前先写“本次唯一操作”；完成后立即退出并保存证据。已经进入执行阶段，就不要重新讨论整个目标的意义。

04

Reusable methods

今天留下的三个可复用方法

  • 案例项目沟通：需求 → 报价 → 下单 → 交付/测试 → 部署 → 售后；部署范围必须在最开始说清。
  • 案例内容隐私：隐藏昵称、题目与敏感信息，只保留能说明交付能力的部分。
  • 视频迭代：先用现成脚本与轻量设备完成第一版，再根据真实数据继续优化，不把“一次做完美”当成起点。
“如果已经到了执行阶段，就不要去探讨这种问题了。”
“你一开始可能做得很差很垃圾，慢慢地迭代得越来越好。”
05

Guardrails

停止、继续与待核

停止做

  • 在一天开始或执行阶段后刷 B 站短视频。
  • 已经知道要做什么时，用野心和意义问题代替执行。

继续做

  • 沿用已经想好的脚本和手机端 PPT，先交付再迭代。
  • 继续保留字幕、隐私打码与手机端内容区适配。

事实边界

“Sonnet 5.5 最便宜且最好用”、模型蒸馏关系、手机用户只看画面中间等说法均没有可靠证据，继续保持待核。

Third-person review

第三人称审视

这个人有很强的目标叙事，也能在计划被打乱后继续行动。但他常把高刺激平台当作工作入口，又在执行起点转向研究和意义追问。

最大 Bug：把“研究清楚、剪完、流程跑通”与“已经产生外部发布结果”混在一起。

最迫切的修复：每次账号更新都必须以公开链接或上线截图收尾。不要再同时设计三个账号的完整打法；先让剩余两个账号各出现一个可见结果。
